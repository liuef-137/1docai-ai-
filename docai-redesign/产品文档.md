# DocAI 智能合同分析平台 - 产品设计文档

> 最后更新：2026-07-12

---

## 一、项目概述

DocAI 是一个面向中小企业的 AI 智能合同文档分析平台。用户上传合同文件或粘贴文本后，AI 在数秒内完成分析，提供合同风险分析、概括总结、通俗理解三种模式。

### 目标用户
中小企业主、创业者、个体户等没有专业法务团队的人群。

### 核心价值
用 AI 替代传统法务咨询，降低约 90% 的成本，让每个人都能享受专业级合同风险分析。

### 当前状态
Phase 1 已完成，公测免费阶段。部署在 `docai-analyzer.vercel.app`。

### 技术栈
Next.js 14 + Tailwind CSS + Claude/GPT API，部署在 Vercel 免费版。

### 运营成本
月运营约 100-500 元（主要是 AI API 调用费）。

## 二、功能优先级分析（路演版）

### S 级 — 核心可交互功能（路演必做）

| 功能 | 说明 | 实现方式 |
|------|------|---------|
| **企业风控偏好配置** | 用户设定风控红线，AI 针对性分析并高亮触碰红线的条款。差异化壁垒功能，越用越精准。 | 前端表单 + AI Prompt 拼接 |
| **分析进度条（Streaming）** | 逐字显示分析结果，配合进度条和动态提示。让产品看起来"很智能"。 | SSE / Streaming API |
| **一键复制修改话术** | 每条改进建议附带复制按钮，用户可直接粘贴到微信/邮件。Clipboard API，成本极低。 | Clipboard API |
| **智能摘要卡片（一键转发）** | 分析结果生成精美长图，一键保存分享。传播性极强的功能。 | html2canvas |
| **字数预警 + 超限分割** | 字数计数器 + 接近上限警告 + 超限阻止。成本控制底线，防止 API 被刷。 | 前端 JS 计算字数 |
| **合同档案库** | LocalStorage 存储历史分析记录，支持搜索、分类筛选、风险概览。路演时展示"越用越有数据"。 | LocalStorage + UI 展示 |

### A 级 — 高保真 UI 展示（静态 mockup，不可交互）

| 功能 | 说明 | 展示方式 |
|------|------|---------|
| **合同对比分析（红黑线）** | 两份合同并排对比，红/绿色标注差异，AI 差异解读。视觉冲击力极强。 | 高保真静态 mockup + "即将上线" 横幅 |
| **风险整改追踪器** | 将分析从"一次性"变成"持续性"的工作流闭环。 | UI 概念展示 |
| **合规清单自查** | 增加信任感的教育性功能。 | 作为分析结果页的一个 tab 展示 |

### B/C/D 级 — 文字提及或不提及

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 常用条款模板库 | C 级 | 仅文字提及"规划中"，不做 UI |
| 人工兜底入口 | C 级 | 商业模式页提一句"未来对接律师服务" |
| 行业避坑雷达（UGC） | D 级 | 远期愿景，路演不提 |

### 体验优化决策

| 功能 | 决策 | 理由 |
|------|------|------|
| 粘贴即分析（自动触发） | **不做** | 用户粘贴错误时已触发分析，浪费 API。改为粘贴后亮起分析按钮 |
| 推荐追问按钮 | **精简为 2 个** | "帮我起草补充协议"和"如果我是乙方是否公平"，去掉不专业的语气选项 |
| 移动端优先 | **必须重视** | 微信内置浏览器是国内最大入口，路演 demo 必须手机端完美 |

## 四、品牌设计体系

### 视觉风格
专业信赖风 — Legaltech SaaS，传达法律的专业性和 AI 的现代感。

### 配色方案

| 用途 | 色值 | 变量名 |
|------|------|--------|
| 主色：深海蓝 | `#1B365D` | `--color-primary` |
| 主色浅 | `#2A4A7F` | `--color-primary-light` |
| 主色深 | `#0F2440` | `--color-primary-dark` |
| 强调色：翡翠绿 | `#2D9D78` | `--color-accent` |
| 强调色浅 | `#3DBF94` | `--color-accent-light` |
| 强调色深 | `#1F7D5C` | `--color-accent-dark` |
| 背景色 | `#FAFBFC` | `--color-bg` |
| 表面色 | `#FFFFFF` | `--color-surface` |
| 边框色 | `#D8DDE6` | `--color-border` |
| 主文字 | `#1A2332` | `--color-text-primary` |
| 次文字 | `#5A6677` | `--color-text-secondary` |
| 高风险 | `#D45050` | `--risk-high` |
| 中风险 | `#E8A33D` | `--risk-medium` |
| 低风险 | `#2D9D78` | `--risk-low` |

### 字体

| 用途 | 字体栈 |
|------|--------|
| 展示字体（标题） | `'DM Serif Display', Georgia, 'Noto Serif SC', serif` |
| 正文字体 | `'Inter', 'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif` |

### 设计约束

- 阴影：静态元素阴影 alpha <= 0.05
- 圆角：最大 16px
- 标题：中文标题 <= 8 个汉字
- CTA 按钮：中文 2-6 个字
- 每行视觉元素只选一种对齐方式
