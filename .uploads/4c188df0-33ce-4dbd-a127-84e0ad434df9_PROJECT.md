## 1. 项目概述

### 产品定位
AI 驱动的合同文档分析平台，帮助中小企业快速识别合同风险，节省法务成本。

### 核心价值
- **上传即分析**：拖拽上传合同文档或直接粘贴文本，AI 在数秒内完成深度分析
- **三种分析模式**：合同风险分析、概括总结、通俗理解
- **清晰报告**：结构化报告呈现，风险等级一目了然
- **降低成本**：相比传统法务咨询，节省高达 90% 的成本

### 目标用户
- 中小企业主（年营收 100 万 - 5000 万）
- 创业公司创始人
- 个体户/自由职业者
- 企业法务/行政人员

## 5. 技术架构

### 技术栈

| 组件 | 技术选择 | 费用 |
|------|---------|:----:|
| 前端框架 | Next.js 14 (React 18) | ¥0 |
| 样式方案 | Tailwind CSS | ¥0 |
| AI 能力 | Claude API / GPT API | 按量付费 |
| 部署平台 | Vercel (Hobby 免费版) | ¥0 |
| 域名 | https://docai-analyzer.vercel.app (免费) | ¥0 |

### 核心功能

- 🔍 **合同分析**：风险识别、条款分析、改进建议、综合评分
- 📋 **概括总结**：提取核心要点、章节结构、关键信息
- 🗣️ **通俗理解**：法律术语翻译成大白话
- 📄 **文件上传**：支持 PDF/DOCX/TXT/CSV，最大 10MB
- ✍️ **文本粘贴**：直接粘贴合同文字
- 🌐 **中英文切换**：一键切换界面语言
